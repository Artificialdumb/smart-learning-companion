# 提交材料与复核入口

当前参赛交付保存在本地Workspace项目的交付目录，按赛方平台分别提交。

| 材料 | 格式与要求 | 当前内容 |
|---|---|---|
| 设计方案 | PDF，20页以内，10MB以内 | 18页技术方案，含课程分析、数据治理、算法、案例、验证与复算 |
| 任务成果包 | ZIP，50MB以内 | JSON与JSONL结果、字段说明、输入输出样例和操作说明 |
| 演示视频 | MP4，5分钟以内，50MB以内 | 平台操作演示 |
| 现场答辩 | PPTX，10MB以内 | 白底藏蓝技术答辩，围绕问题、架构、实现、验证和下一阶段展开 |
| 项目代码 | ZIP，50MB以内，选交 | 源码、合成样例、依赖锁定、接口文档与CI配置 |

## 共同数据口径

- 每条有效作答按得分比例计一次证据，使用Beta先验平滑，并给出90%区间。
- D01/N01/T01I2为55.6%，区间13.3%—93.2%，1条有效作答。
- D14/N02/T03I2为75.0%，区间36.8%—98.3%，2条有效作答。
- D17/N02/T03I2有效作答为0，指数与区间以null记录，安排补充观察。
- 本地赛题批次含806行原始记录、799个最新事件、785条有效作答、80份个人节点报告和2份班级报告。
- 当前本地运行63项测试，62项通过，1项可选PDF测试按依赖条件跳过。赛题目录与导入回归使用本地资料包实际运行。

## 任务成果包复算

使用`python -m app.cli export --db <数据库> --run-id <批次编号> --out <导出目录>`生成结构化结果。以导出目录作为`build --source`可复算初始诊断、班级比较、计划、规则与题组。教师调整和追问记录通过导出快照查阅。
