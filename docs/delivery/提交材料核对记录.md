## 共同数据口径

- 每条有效作答按得分比例计一次证据，使用Beta先验平滑，并给出90%区间。
- D01/N01/T01I2为55.6%，区间13.3%—93.2%，1条有效作答。
- D14/N02/T03I2为75.0%，区间36.8%—98.3%，2条有效作答。
- D17/N02/T03I2有效作答为0，指数与区间以null记录，安排补充观察。
- 本地赛题批次含806行原始记录、799个最新事件、785条有效作答、80份个人节点报告和2份班级报告（含节点级群体摘要）。
- 默认规则下“已掌握”至少需要5条满分作答；T01I3、T02I3、T03I3截至N02累计4个题位，等级上限为“正在形成”。
- 2026-11-24 在 Python 3.12.13 环境（运行与 docs 依赖）运行66项测试，全部通过，无跳过；赛题目录与导入回归使用本地资料包实际运行。

## 任务成果包复算

使用`python -m app.cli export --db <数据库> --run-id <批次编号> --out <导出目录>`生成结构化结果。以导出目录作为`build --source`可复算初始诊断、班级比较、计划、规则与题组。教师调整和追问记录通过导出快照查阅。
