### 1.4 前端

网页为原生 JavaScript 与 CSS，不引入第三方前端库或 CDN 资源。

### 1.5 预训练模型

仓库与成果包不包含、不下载任何预训练模型权重。赛题批次、案例与成果包均在规则模式下生成，manifest 记录 `recommendation_mode=rules`。可选选材接口（`app/recommendations/local_model.py`）在设置 `STUDY_MODEL` 后调用本机 `127.0.0.1` 上的 OpenAI 兼容 `/v1/chat/completions` 接口，只从已校验的候选材料编号中选一项，超时、不可用或越界时回退规则首选。使用者接入本地模型时，在 manifest 的 `recommendation_mode` 之外另行登记模型名称、版本与许可。

## 2 数据与内容来源

| 内容 | 来源 | 位置 | 处理 |
|---|---|---|---|
| 赛题资料包（课程要求、题目与材料、模拟学生、测验节点、作答记录 CSV，课标与教材 PDF） | 赛方提供，**受限使用** | 仅本地 `data/`（已在 `.gitignore` 中忽略） | 不提交仓库、不进入 CI、不随代码分发；构建时记录各文件 SHA-256 |
| 赛题数据的分析结果与成果包 | 由赛题数据生成 | 仅本地 `outputs/`（已忽略） | 按赛题规则使用，提交前核对引用范围 |
| 课程对照数据（教材章节页码、课标条目、指标关系） | 团队对照赛题资料包中的课标与教材 PDF 整理 | `app/catalog/curriculum.json` | 只记录页码与条目编号，不复制教材正文；PDF 摘要不一致时不附加精确页码 |
| 合成联调数据 | 团队自编，不含任何真实或赛题学生数据 | `fixtures/synthetic/` | 可公开，用于测试与演示 |
| 错因追问题组（8 套 24 题） | 团队自编 | `app/diagnosis/probes.py` | 原创，不来自教材或赛题 |
| 学习提示与复查条件模板 | 团队自编 | `app/rules.json` | 原创 |
| 赛题样例编号（D01、N01、T01I2、DR0001、Q015P3 等） | 赛题资料包 | `app/rules.json` 导出案例配置、演示说明、PPT | 只引用编号，不包含原始作答内容 |

## 3 代码与资料使用

1. 代码使用许可由团队确定，并与赛题资料的授权范围分别管理。
2. 赛题数据回归测试（`tests/test_catalog.py`、`tests/test_ingestion.py`）使用本地资料包运行：`STUDY_CONTEST_SOURCE=data/赛题资料包 python -m unittest discover -s tests -v`。
